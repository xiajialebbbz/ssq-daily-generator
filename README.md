# 双色球每日娱乐选号

一个本地运行的双色球娱乐选号小应用。

## 功能

- 打开页面时自动同步福利彩票官网最新开奖数据
- 基于近 10 年历史形态做娱乐选号
- 使用贝叶斯平滑评分、候选池抽样、尾数分散和个人避重
- 生成 10 注并拆成 2 条短信，每条最多 5 注
- 保存“我买的号码”到本地 JSON

## 启动

双击：

```bat
start_ssq_app.cmd
```

或命令行：

```bash
node ssq_server.js
```

然后打开：

```text
http://127.0.0.1:8787/
```

## 数据文件

- 开奖缓存：`data/ssq_profile.json`
- 本地购买记录：`data/purchases.json`

`purchases.json` 是个人投注记录，默认不会提交到 GitHub。

## 说明

本工具仅作娱乐参考。双色球每一种合法组合的理论中奖概率完全相同，本工具没有概率优势。
